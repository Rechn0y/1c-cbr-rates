# 1c-cbr-rates

# Загрузка курсов валют ЦБ РФ

Внешняя обработка для 1С:Предприятие 8.3 (управляемые формы). Получает актуальные курсы валют ЦБ РФ через JSON-API и записывает их в регистр сведений `КурсыВалют`.

Подходит для конфигураций на БСП: УТ 11, ERP, Комплексная автоматизация.

## Возможности

- HTTP-запрос к сервису по HTTPS с проверкой кода ответа и таймаутом
- Разбор JSON в `Соответствие` и заполнение таблицы значений
- Отбор валют по буквенным кодам (USD, EUR, CNY)
- Запись в регистр сведений в одной транзакции; валюты сопоставляются со справочником одним запросом, без обращений к базе в цикле
- Ошибки пишутся в журнал регистрации, пользователю показывается краткое описание
- Разделение клиентского и серверного кода, немодальные диалоги через `ОписаниеОповещения`

## Источник данных

[cbr-xml-daily.ru](https://www.cbr-xml-daily.ru/) — открытое зеркало ежедневных курсов ЦБ РФ в формате JSON.
